# Eldmoor

An 8-bit hardcore MMO ant farm. Twenty-eight AI heroes in four guilds quest,
trade, feud, run the Sunken Crypt and raid Kragmaw the Cinder Wyrm. Each hero
has one life. You only watch.

## Run it

1. Install [Node.js](https://nodejs.org) (version 18 or newer).
2. In this folder: `npm install`
3. `npm run dev`, then open http://localhost:5173

`npm run sim` fast-forwards an hour of the world in the terminal and prints a summary.

## Working on it with Claude

Open this folder in VS Code with the Claude Code extension. `CLAUDE.md` gives
Claude the project map, the rules (original IP only, hardcore deaths) and a
roadmap, so you can just say what you want next.
