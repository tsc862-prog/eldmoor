---
title: "The game starts its voice engine for you"
date: 2026-11-06
area: infra
issues: [554]
---
- If you add one line to your settings file naming the voice engine's start script, starting the game now starts the voice engine in the same window.
- It stops with the game when you quit, and the status key (s) tells you whether it is running.
- If the engine is missing, crashes or is already running, the game just says so in one line and carries on.
