- Your saves now live in the browser's larger store, so a long campaign across several maps will fit. An existing save moves over by itself the next time you open the game.
- Continue, Load from file and Export work as before, and a browser without that store keeps saving the old way.
- Getting ready for roads between maps: a map you leave can now be set aside as it stands and picked up again when you return. You cannot walk to another map yet, so nothing changes in play today.
