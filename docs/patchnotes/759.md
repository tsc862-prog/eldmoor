- With the Table switched off, an agent hero who goes down now makes a death save every 20 game minutes, and companions nearby are woken at each one so they can come and help.
- The Dungeon Master describes a hero going down, each death save and how it ends; when the DM is slow or away, a short scripted line does it instead. The dice still decide who lives.
