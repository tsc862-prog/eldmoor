- The model pickers now list OpenAI models cheapest first with their price per million tokens, and a short list of OpenAI models in your settings file (for example gpt-6-luna and gpt-6.1-terra) shows only the models you choose.
- Local and OpenAI heroes no longer answer a Table scene twice, so the refused "already acted" calls and their wasted model calls are gone.
