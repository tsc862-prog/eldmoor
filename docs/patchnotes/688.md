title: Cheaper model pickers, quieter Table scenes
date: 2026-11-03
area: ai
issues: [681, 677]
---
The model pickers now list OpenAI models cheapest first with their price per million tokens, and `OPENAI_MODELS` in `.env` (for example `gpt-6-luna,gpt-6.1-terra`) shows only the models you choose.
Local and OpenAI heroes no longer answer a Table scene twice, so the refused "already acted" calls and their wasted model calls are gone.
