---
title: See how a hero's gambits differ from its class
date: 2026-11-03
area: ui
issues: [679]
---
- The Agent tab now says in one line how a hero's gambits differ from its class preset, and marks each rule: + added, ~ changed, ^ or v moved, off. Rules it dropped are listed last, struck through. Hover a marked rule to see the class's version and the hero's reason.
- A weakened or missing flee, potion or defend rule is flagged in red. The same summary line appears on the Stats tab and in a new Agent row of the Fellowship sheet.
