Fellowship phase A built 2026-11-01 on branch ai/fellowship-a (PR "Fellowship phase A"). Phase B (table runner, party tools, Table mode) waits on #93 multi-agent; #94 (party frames, side-by-side sheet) builds on src/ui/fellowship.js helpers.

- Owner rule (overrode the issue's 3-5): exactly 5, slots tank (Warrior), healer (Priest), dps1-3 (Mage/Hunter/Rogue, distinct preferred). Replacement fills the same slot: most-bonded living hero of the class (bond>0 or level within 3 of the party mean), else the next recruit (consumes an S.recruits entry, makeHero now).
- Data: S.fellowship {id,name,fac,hall,slots,ids,founded,day,log,past,npcs,dmSeen,ai,enrich,seq}; a.fellow, a.fellowRole (slot key), a.fellowFrom (old a.town; members lodge in the hall town so they muster at one gate), a.fellowBrain (brain enabled by the Fellowship), a.persona, a.backstory {paras,summary,link}, a.memory {recent<=12, long<=800 chars, stances, n, longAt}. All plain, saved; SAVE_VERSION 4 (no-op migration).
- Hooks (insert only): index.js fellowshipTick after partyTick; party.js seekParty skips fellows, partyTick skips the level-gap disband for p.fellow; history.js onRecord observer (record lines -> memories); dm.js `watched` also true for fellow adventures (always told); brain.js snapshotFor adds s.fellow=fellowCard(a) + askRelay(kind,snap,timeout) export; player.js status adds r.fellowship; draw.js 'fellow' view uses cam.frame (set by ui/controls.js).
- Relay writing kinds: KINDS += persona, backstory, memory (WRITE_KINDS, WRITER preamble, PROMPT_VERSION 4). KIND_MODEL persona/backstory = claude-sonnet-5-5 (RELAY_WRITE_MODEL overrides), memory = default Haiku. Sonnet 5.5 rejects thinking 'disabled' -> thinking {type:'between_tools'} + effort low, plus fallbacks:'default' with beta server-side-fallback-2026-07-01 via client.beta.messages.create (Haiku 5.5 has no server fallback). KIND_TIMEOUT persona 40 s, backstory 60 s, memory 15 s. Schemas: persona stances keyed by companion ids (dynamic object schema); backstory link_hero enum of companion names, link_kind enum; checkWriting validates and cleanText caps every field. MAX_TOKENS persona 1200, backstory 2400, memory 500.
- Enrichment is fire-and-forget on join: backstory then persona; never overwrites an edited sheet; cost/ms summed on F.enrich. Not measured live yet: the user's relay on :8787 ran main's code ("unknown kind" for persona) on 2026-11-01, so the live call was skipped. Expect roughly $0.01-0.02 per member (Sonnet $2/$10 per 1M, ~1.5k in / ~1k out).
- Tests: seeded `npm run sim -- 60` identical to origin/main (no Fellowship = no-op); savecheck founds one (ai:false) and checks members; braincheck has a writing-kinds block with a fake client exposing beta.messages; scratch scripts (fellowrun, cohesion, enrichcheck, stubbed-DOM smoke) live in the session scratchpad only. Cohesion measured: full 5-member party ~80% of samples; Crypt drafts pull members out (two early deaths "lost in The Sunken Crypt").
- Pitfall: writing JS through `node -e` / python strings ate backslashes (\b became a backspace, \u0000 became NUL). Use the Write/Edit tools for any line with regex escapes, then scan for control chars.
