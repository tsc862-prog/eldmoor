Agent player built for issue #75 (PR from branch ai/agent-player, 2026-11-01). An AI agent plays one hero through 23 MCP tools.

- Layers: `src/sim/player.js` (playerAct/playerUpd/markPlayer, DOM-free) -> `src/sim/player-host.js` (hostCall: polls the `wait` tool against game time, 45 s real cap) -> host = browser page (`src/ui/player-bridge.js`, ws://127.0.0.1:8787/play) or `scripts/play-headless.mjs` (Node world, port 8789). `scripts/relay-mcp.mjs` attachPlay() adds /mcp (stateless streamable HTTP, enableJsonResponse, one McpServer per POST), /play/call, /play/narrate, /play/health to any http.Server by re-ordering 'request' listeners; relay.mjs gets one import + one call (`--play-only` runs without a key). `npm run mcp` = stdio server forwarding to PLAY_URL/play/call.
- WS protocol: page -> {type:'hello',hero:{id,name}}; relay -> {type:'call',id,tool,args} / {type:'narrate',text}; page -> {type:'result',id,result}. Origin must be the dev origin; /mcp and /play/* refuse any Origin header; Host must be localhost.
- Hook points: index.js step `if(!(a.player&&playerUpd(a,dt)))updAgent(a,dt)`; dm.js choice case one call `playerBranch(adv,sc,a,S2)` (src/sim/player-choice.js, no import cycle) returning 'wait' until choose() or CHOICE_MIN=180 game min; branch logged by dmlog with why 'player choice'. take_adventure never edits dm.js: it hides other open hooks (phase 'held') and sets h.for=a.id so the scripted pickHook takes it without a roll, then restores. Coordinator asked: only that one dm.js hook.
- Reflexes: fight flee below 15% (flee_below arg), hunt cmd stops at 45%*retreat trait, idle bag>=8 goes home; crypt/raid drafts and unrequested parties are declined (a.cryptOk/raidOk/partyOk). Rate limit 12 world-changing calls per game hour.
- Runner `scripts/agent-player.mjs`: @anthropic-ai/claude-agent-sdk 0.3.316 query() per "turn"; model claude-sonnet-5-5 (AGENT_MODEL), effort medium, tools:[], allowedTools:['mcp__eldmoor'], permissionMode 'dontAsk', settingSources:[], settings.autoCompactEnabled, maxTurns 12 per turn, maxBudgetUsd; cwd must exist (logs/) or spawn fails with misleading "native binary failed to launch (ENOENT)". total_cost_usd is cumulative across resume -> per-turn = delta. Session in logs/agent-session.json keyed by hero id+name; `--env FILE` loads a .env elsewhere (worktrees have no .env).
- Measured live 2026-11-01 (headless, warm 15, level 7 Mage, Sonnet 5.5 medium): 5 turns, 38 tool calls, $0.103 total; turn 1 $0.037 (cache warm-up), later turns $0.014-0.020; ~32-43 s per turn; ~0.6-1.3 k output tokens/turn, >90% input cached. Agent behaved sensibly (rested, fled L11, bought gear) but rarely journals and sometimes replaces a command at once (rest then hunt).
- Per-hero runner settings (coordinator ask for "Mixed minds"): sess.runner = {provider, model, effort} in logs/agents/<id>.json via runnerSettings() (flags > saved > env defaults; provider switch drops saved model). Runner refuses non-anthropic ("not supported yet, see the Mixed minds issue"). Relay is provider-neutral (routes by hero id only).
- Multi-agent (#93, branch ai/multi-agent): several agent heroes, one runner each. Routing: hero id via `X-Eldmoor-Hero` header or `?hero=` on /mcp, `hero` field on /play/*; no hero = old path (first living seat). Backend API is now call(heroId,tool,args)/narrate(heroId,text)/info()->{connected,heroes:[{id,name,alive}]}/links(map). WS: page hello {heroes:[...],hero}, relay call {id,hero,tool,args}, narrate {hero,text}, relay->page {type:'links',links:{id:state}}. Runner claims: POST /play/claim|release {hero,runner}, CLAIM_MS 30 s (runner refreshes every 10 s), 409 when held. Link = connected (call in flight or within LINK_MS 20 s) / waiting (claim live, quiet) / none. attachPlay takes `now` (tests skew time). player.js: playerHero(id)/playerSeat(id)/playerSeats(). Sessions: scripts/agent-sessions.mjs (no SDK import), logs/agents/<id>.json, name mismatch or --new -> moved to logs/agents/old/, legacy logs/agent-session.json migrated once; pickHero() picks --hero or first free.
- Measured live 2026-11-01, two runners at once on one headless world (Sonnet 5.5 medium, levels 5 and 7): 9 turns total, $0.175 (Wynis 4 turns $0.111, Ssilul 3 turns $0.064); $0.016-0.033 per turn, 7-105 s per turn, 5-15 tool calls, >90% cached. A turn that hits --tool-turns (12) threw error_max_turns and used to end the run; now it just ends the turn. Resume from logs/agents/<id>.json verified.
- Tests: `npm run playcheck` is now driven: hostCall gets {nap: advance, now: vclock} so mock waits step the world (12 frames per 16 ms) and runs depend on the seed only (~3 s); HTTP sections switch to the real ticker. Swept 40 seeds green after fixing seed-specific test flakes (silent-agent hero must leaveParty properly, clear weather, wave off mobs; take_adventure can be "turned away" by dmDepart -> try next job). Browser bridge tested in Node by stubbing globalThis.WebSocket = class extends ws client with {origin} and globalThis.localStorage. braincheck flake (#93): rejected Mind entries < 3 when stats.rejections counted answers whose entries were already closed -> wait on minds() rejected count; also the "enemy 30 tiles away" check picked enemies already named in chat/history. Seeded `npm run sim -- 60` identical to main (scratchpad seeded-sim wrapper). Pitfall hit: a `//` comment inserted mid-line in index.js swallowed `partyTick()` and stalled leveling; always diff seeded sims vs main.
