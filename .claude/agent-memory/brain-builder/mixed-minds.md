Part 2 (local agent runner):
- scripts/local-agent.mjs localTurn({chat, call, sess, prompt, model, toolTurns, on, opts}): Ollama /api/chat with `tools` (PLAYER_TOOLS -> function tools), cleanArgs validates/coerces against the tool table (rejections go back as tool results), parseTextCall for <tool_call> text, JSON-action fallback (e.noTools from 400 "does not support tools" -> format schema {tool,args,narration}, tool 'end'), endOnWait: after a successful wait one tools-free call gets the narration (4B model never stopped on its own: every turn hit the cap before). History in sess.local {mode, history (turn:1 marks turn start), tokensIn/Out, seconds, dropped}; tool results kept 400 chars, assistant 800, trim oldest whole turns past 24k chars. num_ctx 16384 default.
- ollama adapter chat() added. agent-player: RUNNER_PROVIDERS ['anthropic','ollama'], runLocal(); a claude-* model is dropped when switching to ollama. fellowship.mjs: per-member local path (localMemberTurn), no-key start allowed (only local members play), skip() records skipped members (fixed a re-add-every-second loop for unsupported providers).
- Claims carry {provider, model} (runnerInfo validation); /play/health heroes get runner + claimed; links WS message gets `runners` map; UI runnerTag(a) in player-bridge -> mind row Agent mode, Agent tab, Minds panel. pickHero uses `claimed` (a just-released runner still shows link 'connected' for LINK_MS 20 s and was wrongly refused).

Part 3 OpenAI (branch ai/openai-provider, 2026-11-01): scripts/providers/openai.mjs = Chat Completions (not Responses: the agent loop is the Ollama messages/tool_calls loop, OPENAI_BASE_URL compat, loop keeps its own history), strict json_schema, max_completion_tokens, reasoning_effort:'none' always (Chat Completions allows function calling on gpt-6.x reasoning models only with it; model that 400s on the field is retried without and remembered). No default model in code (OPENAI_MODEL or caller picks). PRICES from developers.openai.com/api/docs/pricing read 2026-11-01 (platform.openai.com/docs/pricing 301s there); unknown model -> usage.cost 0 + costKnown:false + costNote 'unknown'. 429 errors carry status+headers{retry-after} so providers/limiter.mjs rateLimitOf works; relay makeLimits has openai (RELAY_OPENAI_CONCURRENCY, 4); call() does not retry itself, chat() (agent runner, no relay queue) waits retry-after up to 30 s. chat() translates the loop's Ollama-shaped messages to OpenAI (toOpenAI: ids, string args, unanswered calls filled with '(not run)'), so local-agent.mjs is unchanged for Ollama; localTurn now also sums cost/costKnown; paidLine prints '| turn $ | run $ | session $' (runners.mjs reads '| run $'). scripts/agent-chat.mjs openaiRunner() preflight (key, model, models list) used by agent-player runOpenAI and fellowship (m.paid). Runner reads OPENAI_API_KEY from its own env/.env like the Claude runner. Test: npm run openaicheck + scripts/mock-openai.mjs (mock enforces tool-message shape). No live OpenAI call was ever made.
