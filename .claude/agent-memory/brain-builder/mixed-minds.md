Part 1 built 2026-11-01 on branch ai/mixed-minds-1 (PR "Mixed minds part 1"). Part 2 (provider-neutral agent runner) waits on Fellowship phase B (table runner); do not start it before that merges.

- Adapters: scripts/providers/{anthropic,ollama,openai,google,index}.mjs, one interface {name, local, configured(), status(), call({system,user,schema,maxTokens,model,effort,signal,timeoutMs}) -> {text,usage:{in,out,cost},model,ms}}; errors carry .raw and .result (usage) so the relay still counts tokens on refusal/cut-off. anthropic.mjs owns DEFAULT_MODEL/PRICES/costOf (relay.mjs re-exports them; agent-player imports PRICES from relay). openai/google are stubs ("not configured" / "not built yet") with TODOs: prices must be checked live, never from memory.
- Relay: request may add provider/model/effort (checkRequest: provider in PROVIDERS, model /^[A-Za-z0-9][\w.:\/+-]{0,99}$/, effort low|medium|high). Reply and error replies carry provider+model. Log line `[relay] kind hero provider/model in= out= $ ms`; verbose records provider, model. /health adds byProvider stats, providers:{name:{ok,models,local,error?}} (Ollama via /api/tags, cached 10 s, 1.5 s timeout) and localTimeout. LOCAL_TIMEOUT decide 8000 / write max(30000, KIND_TIMEOUT) (env RELAY_LOCAL_TIMEOUT, RELAY_LOCAL_WRITE_TIMEOUT). Relay now starts without ANTHROPIC_API_KEY (warns; Claude calls fail -> scripted).
- Ollama: native POST /api/chat, format = the JSON schema, stream:false, keep_alive 30m, num_predict = 2x MAX_TOKENS, think:false. PITFALL measured live: qwen3.5:4b (a thinking model) without think:false cut off EVERY reply (thinking ate num_predict). A model that rejects `think` (400 mentioning think) is retried without it and remembered per adapter.
- Sim: a.brainCfg = {provider, model?, effort?} (same shape as runner settings sess.runner from #93), setMind/mindCfg/modelTag/mindTag in brain.js. ask() sends it, timeout CFG.localTimeoutMs 9000 for local (vs timeoutMs 3000); askRelay(kind,snap,timeout,hero) stretches to CFG.localWriteMs 35000 for local; fellowship.js passes the member. Mind entries get provider, model, usage.cost; chat speak(a,text,trigger,tag) stores e.model. Tag format "qwen2.5:14b · local" / "claude-haiku-5-5"; mindTag(a) "Claude" when unset.
- UI: src/ui/mindpick.js (renderMindRow/mindAct/mindChange/mindRowSig) used in the Fellowship roster rows; polls relay /health every 15 s; provider switch picks the first pulled model when the default (qwen2.5:14b) is not pulled. fellowship.js skips rebuilds while a select has focus.
- Measured live 2026-11-01 (owner's RTX 4090, only qwen3.5:4b pulled, test relay on :8797): townPlan 0.3-0.7 s (first call ~5 s before think:false fix included load), say ~0.25 s, ~730 in / ~40 out tokens, $0. Answers legal (schema-forced) but reasons weaker (contradicted itself once).
