Built 2026-11-01 on branch infra/runner-pacing (PR "Closes #126"). Owner saw 20 local turns in under a minute; coordinator added the lazy-model bug (qwen2.5:14b runners made 0 tool calls in 61-116 of 80-120 turns, narrating a long-over fight from its own earlier replies) and "6 minds" (5 Fellowship + DM).

- Protocol: POST /play/pace {hero, runner, since?, minutes?, wake:'now'|'all', realMs?} on relay-mcp (claim-checked, NOT counted as link activity, not logged) -> backend.call(id,'pace',args) -> player-host hostCall special-cases tool 'pace' (MCP and /play/call never offer it) -> src/sim/pace.js paceCheck. Answers {wake:'now'|'soft'|'heartbeat'|null, why, since, clock, table} or {ok:false, dead|gone}. {brief:true} returns the state header (state, doing, HP, place, foe, scripted, table, unread news) at once. Old relay (404) or old page ("Unknown tool pace") -> runner falls back to real time as if 1x. localBackend answers "not agent-played" with offline:true: pacer must treat that text as gone (first test hung on it).
- Wake levels in notify.js: ev(a,text,urgent,wake); urgent=2 -> e.w=2 'now' (attacked, duel, assist, badly hurt, choice in player.js; TABLE/YOUR TURN in table.js; camp alarm). Other urgent and wake=1 (party line, narrator, npc speech) -> 'soft'. Events read = e.n > a.playEvSeen, never consumed.
- Runner side scripts/pacing.mjs: makePacer (gap with wake:'now' long-poll, then 'all'; NOW_BURST 4), defaults heartbeat 240 game min, min gap 20 s, max fails 5 (flags --heartbeat/--min-gap/--max-fails, env AGENT_*; fellowship --cadence = gap). turnCap: ollama Infinity unless --max-turns, else 20 (hero) / 6 (fellowship member) / 12 (DM). failTracker; localWorked = tools>0, not all rejected, not (repeat && no act). Removed the old post-turn `status` call (it stole the hero's events).
- local-agent.mjs: REPROMPT once when the first answer has no tool call; history keeps only the latest narration (msgs flagged narr:1); similar() word overlap >= .8 vs sess.local.lastNarr -> repeat; turn line flags "re-prompted to act" / "empty turn (...)".
- player.js (minimal, shared with #124): PK.IDLE 120; a.playActAt set on a successful act tool and on markPlayer; playerUpd returns false (scripted updAgent plays) when no cmd, no adventure, no table and idle >= IDLE; a.playIdle + one event. tablecheck "leader left" now uses the farthest point (takeover brings the silent leader home).
- Supervisor: maxTurns null unless asked (no --max-turns arg); view adds turnCap text, turnsPerMin (10-min window), lastTurnAt/Ago, pace (last "[pace]" line). MAX_RUNNERS 6 (RELAY_MAX_RUNNERS), SEATS 6: Fellowship members / Fellowship runner / DM always fit. Claude slots now leased per turn: POST /play/runner/slot {key} (waits <= 20 s, else busy, child retries), /slot/release {lease}; child env ELDMOOR_RUNNER_KEY; leases dropped on child exit, expire 15 min; starting never refused for slots. UI: runnerPick returns a span with mind + turn-cap selects (data-runturns).
- Tests: localcheck section 4 (in-process world at 8x + real runner children: quiet heartbeat gaps, 'now' in 36-42 ms inside a 4 s gap, soft at ~4.0 s, leave agent play ends runner, mock-lazy re-prompt/stop after 3 empty, idle takeover). runnercheck: lease handoff, six seats with RELAY_MAX_RUNNERS=2 + RUNNER_CLAUDE_MAX=1. Old sections set AGENT_MIN_GAP 0 / AGENT_HEARTBEAT 30 in child env. Seeded sim -- 60 identical to base.
- Pitfall again: python heredocs in bash eat backslashes (\n, \\d); use the Edit tool for JS lines with escapes.
